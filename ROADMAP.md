# Roadmap

The order below keeps each claim behind the evidence required to support it.

1. **Keep host behavior reproducible.** Maintain the connected executor,
   malformed-input refusals, identity guards, and independent host controls.
2. **Resolve graph gaps.** Replace placeholders only when the source contract
   and dependency evidence support the replacement. The current record has
   91 placeholders among 94 graph entries.
3. **Close cold-start semantics.** G8 output is blocked and G4 selection remains
   ambiguous. Neither is promoted to a working path by assumption.
4. **Renew physical authorization before another launch.** The current
   allowance is exhausted at 5/5/0. Any next GPU experiment needs a new,
   scoped authorization and a bounded completion contract.
5. **Expand hardware and interop coverage only after those gates.** A second
   machine, another gfx1030 device, and D3D12/HIP presentation each need their
   own reproducible evidence.
6. **Treat complete workload execution as a separate milestone.** A complete
   neural network, cold frame, game frame, and temporal sequence remain
   unproven.

Candidate-F remains frozen historical work. No roadmap item changes its status
or reuses its evidence as proof for Phase 16BK.
